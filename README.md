# Predictive Analytics – Student Pass Prediction

## About
This project uses predictive analytics to predict student pass/fail outcomes based on student performance data.

## Dataset
The project includes raw student data and processed datasets.

## Steps Performed
- Data cleaning
- Handling missing values
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Student pass prediction

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Project Files
- `data/` – Raw dataset
- `outputs/` – Cleaned and processed datasets
- `Predictive_Analytics_Student_Pass_Prediction.ipynb` – Main notebook
- `requirements.txt` – Required Python libraries
